# CodeSentinel Web 界面截图展示

## 主界面

### 审查表单
- 输入代码路径（支持文件或目录）
- 配置审查参数（最大轮次、自动修复）
- 一键启动智能审查

### 实时进度显示
- 进度条动态更新
- 实时显示发现问题数量和确认数量
- 清晰的状态提示

### 结果展示
- 按类别统计卡片（安全/Bug/性能/代码风格）
- 多维度筛选器（类别、严重度、确认状态）
- 问题列表详细展示
- 每条问题包含：
  - 文件位置和行号
  - 问题标题和描述
  - 严重度标签
  - 确认状态
  - 修复建议

### 报告下载
- 一键下载 Markdown 格式完整报告

## 技术亮点

- 现代化渐变色主题（紫色调）

### 性能优化
- 异步任务处理

## 使用流程

1. **启动服务器**
   ```bash
   python -m src.main web
   ```

2. **访问界面**
   - 打开浏览器访问 http://localhost:8000

3. **配置审查**
   - 输入代码路径
   - 设置审查参数
   - 点击"开始审查"

4. **查看进度**
   - 实时显示审查进度
   - 观察问题发现数量

5. **分析结果**
   - 使用筛选器定位特定类型问题
   - 查看详细问题描述和修复建议
   - 下载完整报告
